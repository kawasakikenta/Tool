# かんたん業務フロー作成

図形を直接操作する「図で編集」と、Mermaidのように工程をつなぐ「テキスト」の両方で、担当者・部署ごとのスイムレーン型業務フロー図を作成できるHTMLツールです。自動配置した図を、ドラッグで自由に調整できます。

このリポジトリには、ほかに Google Apps Script の `CalendarToSheet.gs`（カレンダー予定の転記）と `Shift.gs`（シフト自動割当）が入っています。この2本は `index.html` とは無関係で、使い方は「[Google Apps Script（CalendarToSheet.gs / Shift.gs）](#google-apps-scriptcalendartosheetgs--shiftgs)」にまとめています。

## 使い方

`index.html` をブラウザで開くと、「図で編集」が表示されます。

1. 左側の「処理」「判断」「開始・終了」で図形を追加します。「担当」でレーンも追加できます。
2. 図形を選び、左側で名前・種類・色・担当を変更して「変更を反映」を押します。
3. 図形をドラッグして位置を調整します。別のレーンへ移すと担当も変わります。「グリッド」を外すか、Shiftを押しながら移動すると細かく配置できます。
4. 始点を選んで「この図形からつなぐ」を押し、終点をクリックすると接続できます。Escでキャンセルできます。
5. 選択した図形は「複製」「削除」で操作できます。線の編集画面では、その線だけを削除することもできます。

「戻す」「やり直す」は図形の移動・編集・追加・接続・削除・配置設定・テキストの変更に対応します。履歴は最大80操作で、再読み込みするとリセットされます。図形を削除すると、その図形につながる線も削除されます。前後の図形を勝手につなぎ直すことはありません。

「自動整列」で現在の向きの手動配置を解除できます。横方向と縦方向の配置は別々に保存されます。配置・図形の色・担当の変更も自動保存、TXT保存、SVG／PNG出力に反映されます。

キーボードでも操作できます。図形を選んだ状態で、矢印キーで移動（Shiftで1px）、Ctrl+Dで複製、Deleteで削除、Ctrl+Zで戻す、Ctrl+Shift+ZまたはCtrl+Yでやり直します。入力欄を編集中は文字入力が優先されます。MacではCtrlの代わりにCommandも使えます。

## テキストで入力

左側の「テキスト」へ切り替えると、次のように入力できます。

```text
営業:
問い合わせ受付 → 内容確認 → 見積作成

責任者:
見積作成 → 見積承認

営業:
見積承認 → 受注 → 納品完了
```

入力内容は右側へ即座に図として表示され、ブラウザに自動保存されます。

「TXT保存」で編集用テキストを保存し、「テキスト読込」で再編集できます。保存するファイル名にはフロー名が使われます。ブラウザの自動保存が利用できない場合も、TXT保存で入力内容を残せます。

## 書き方

入力欄の上にある「担当」「開始・終了」「処理」「判断」「矢印」ボタンからも追加できます。図形のボタンはカーソル位置に記法を挿入し、名前を選択するので、そのまま入力して変更できます。「担当」は現在の行の下にレーンを追加します。図形のIDは重複しないように自動採番されます。

- スイムレーン：`営業:`や`経理:`のように、担当者・部署名の末尾へコロンを付けます。
- レーンをまたぐ接続：前のレーンにある工程名を、次のレーンの先頭にもう一度書きます。
- 通常の工程：`受付 → 内容確認 → 見積作成`
- 線の文字：`受付 -- 確認後 → 承認 -- 承認済 → 完了`（途中の線にも指定できます）
- 開始・終了：`開始((問い合わせ受付))`、`完了((納品完了))`
- 条件分岐：`判断{対応可能？}`
- 通常処理：`確認[内容を確認]`
- `→` の代わりに `-->` または `->` も使用できます。

「使い方」ボタンからサンプルを選択でき、完成した図はSVG画像として保存できます。

入力途中の行や、矢印でつながっていない単独の工程もそのまま表示されます。同じ工程を別の行から参照しても、最初に指定した図形と表示名は維持されます。

## 画面から文字を変更

図形をクリックすると左側で編集でき、ダブルクリックすると文字編集画面を開きます。担当レーンの名前はクリックで変更できます。上部の「文字を編集」から対象を選ぶこともできます。表示名だけを変える場合、図形のID・種類・接続は保たれ、同じ図形への参照もまとめて更新されます。空の名前や、別の担当レーンと同じ名前への変更はできません。

## 線に文字や図形を追加

図の線をクリックするか、プレビュー上部の「線を編集」を押します。編集画面の「編集する線」から対象を切り替えられます。キーボードではTabで線を選び、EnterまたはSpaceで開けます。

- 「線に表示する文字」を入力して「変更を反映」を押すと、線の上に文字を表示します。空欄にして反映すると文字を消せます。
- 「図形の種類」と「図形に表示する文字」を指定して「図形を挿入」を押すと、線の途中に処理・判断・開始／終了の図形を追加し、前後を自動でつなぎます。線の文字は新しい図形の手前に残ります。線の文字も同時に変更できます。
- 追加先の担当レーンは編集画面に表示されます。変更は入力テキストにも反映され、自動保存・TXT保存・SVG／PNG出力に含まれます。
- 閉じるボタンまたはEscで、変更を反映せずに編集画面を閉じられます。反映後は入力欄のCtrl+Zで元に戻せます。

画面から追加した表示名は引用符付きの記法で保存されます（例：`工程1["内容 → 確認"]`、`受付 -- "承認後" → 完了`）。矢印や括弧を表示名に含められ、以前の記法もそのまま使えます。

## 重なる線・遠い接続・縦横切り替え

- 線は分岐・合流する位置と経路をずらして描き、色・線種でも区別します。交差部分には白い縁取りを入れています。モノクロ配色でも線種を変えて表示します。
- 同じ図形間でも、文字が異なる線（「はい」「いいえ」など）は別々に表示・編集できます。始点・終点・文字がすべて同じ記述は、同じ線への参照としてまとめます。
- 上部の「遠い線」を「番号で自動省略」にすると、3段階以上離れる接続、戻る接続、2レーン以上またぐ接続を「③へ」のような表示に変えます。
- 線の編集画面にある「接続の表示方法」で、その線だけ「線で表示」「番号で省略」を指定できます。「『遠い線』の設定に従う」で全体設定に戻せます。
- 「③へ」を押すと、同じ番号が付いた接続先の図形へ移動して強調表示します。番号は図形の追加に応じて自動で振り直され、接続先と常に対応します。
- 「図の向き」で「横方向 →」「縦方向 ↓」を切り替えます。縦方向では担当レーンが列になり、工程が上から下へ進みます。文字や図形自体は回転しません。

表示設定は入力テキストの `# @flow` コメントへ自動で保存されます。手動で編集する必要はありません。TXT保存・読み込みで設定も引き継がれ、SVG／PNGにも現在の向きと接続表示が反映されます。古いテキストは横方向・線で表示の設定で開きます。

## 画像・リンクをボードに置く

- スクリーンショットや画像をコピーし、**Ctrl+V**（Macでは⌘V）で貼り付けると、白い枠付きの画像カードを追加します。「画像」ボタンでファイルを選ぶ方法や、キャンバスへのドラッグ＆ドロップにも対応しています。
- カードをドラッグして自由に配置し、選択すると現れる右下のつまみでサイズを変えられます。通常は画像の比率を保ち、Shiftを押しながらのサイズ変更で枠の縦横を自由に変えられます。画像自体は引き伸ばさず枠内に収めます。
- 左側でタイトル、幅・高さ、枠の色を変更できます。複製・削除、矢印キーによる移動、Ctrl+D、Delete、戻す・やり直すも使えます。画像・リンクカードの位置は図の向きを切り替えても保たれます。
- 「リンク」からURLを登録するか、入力欄以外を選んでURLを貼り付けると、リンクカードを追加します。「埋め込みを表示」を押したときに、そのサイトをボード内に読み込みます。埋め込みを禁止するサイトやログインが必要なサイトは「リンクを開く」で確認してください。埋め込み専用URLを提供するサービスではそのURLも利用できます。
- **「ボード保存」**で画像データを含む `.board.json` を保存できます。「読込」から復元でき、別のブラウザやPCへの持ち運びにも使えます。従来のTXTには図形とカードの設定だけが入り、画像データは含まれません。
- 画像はこのブラウザのIndexedDB、入力内容はlocalStorageに自動保存します。ブラウザのデータ削除で消えるため、残したいボードはファイルにも保存してください。保存領域が使えないときは画面上に表示します。
- SVG／PNG出力にも画像とカードの枠が入ります。外部サイトの埋め込みは、タイトルとURLを表示した静止カードとして出力します。

PNG・JPEG・WebP・GIF・BMPを受け付けます（1枚20MBまで）。画像は長辺2000px以内に調整し、GIFは静止画になります。1ボード100カードまで、持ち運び用ボードの画像データは、画像データ（`dataUrl`）の文字数の合計が64,000,000文字までです（base64の文字数で数えるため、ファイルのバイト数とは一致しません。base64は元のバイト数の約4/3の文字数になるため、目安は画像のバイト数で約48,000,000バイトです）。画像は外部サービスへ送信しません。

## 見本のようなシーケンス図を出力

上部の「形式」で「シーケンス図」を選ぶと、登場人物・アプリを縦の列に並べ、やり取りを番号付き矢印で上から下へ表示します。「幅に合わせる」で横幅を合わせ、縦にスクロールして読めます。SVG・PNGに加えて、単独でブラウザ表示できる「HTML保存」に対応しています。

- 最初の切り替えでは、既存のフローの担当レーンと接続を使って手順を作ります。以降は元のフロー図とシーケンス図を別々に編集でき、「フローから再作成」で作り直せます。
- 「見本の47手順」で、添付見本の案件管理シーケンス（7列・47手順）を読み込めます。「戻す」で取り消せます。
- 矢印や左側の「編集する手順」から選び、「誰から」「誰へ」、説明、工程の区切り、操作アイコン、ステータス、ルートを変更します。同じ相手を選ぶと自己処理の折り返し矢印になります。
- メール・通知は破線、却下・失注は赤い破線、将来工程は点線です。凡例は出力にも含まれます。
- 手順の追加・複製・削除・前後への移動に合わせて番号を振り直します。列の見出し、または「登場人物」から名前・補足・アイコン・色・左右の順番を変更できます。手順で使用中の列は、参照先を変更してから削除します。
- 「補足・注記」は1行ごとに追記できます。長い説明は改行し、必要な高さを取って表示します。
- 「読込」で今回の添付見本と同じ `P` / `R` データ形式のHTML、またはこのツールが出力したシーケンスHTMLを読み込めます。HTML内のJavaScriptを実行せず、対応するデータだけを読み取ります。任意のHTMLページを図に変換する機能ではありません。
- HTMLにはシーケンスの編集データも含めます。画像カードも含めて編集状態を移す場合は従来どおり「ボード保存」を使ってください。HTMLの再読込は登場人物・手順・注記が対象です。

1つのシーケンス図は40列・500手順までです。大きな図のPNGはブラウザで扱える寸法に合わせて縮小します。細部を保って出力する場合はSVGまたはHTMLを使えます。

## Google Apps Script（CalendarToSheet.gs / Shift.gs）

`CalendarToSheet.gs` と `Shift.gs` は、Google スプレッドシートの「拡張機能 → Apps Script」に貼り付けて使うスクリプトです。ブラウザ用の `index.html` とは互いに依存しません。2本も互いに依存しません。

### 2本を同じスプレッドシートに入れる前に

2本は **別々のスプレッドシート（別の Apps Script プロジェクト）で使います**。同じプロジェクトに入れると、次の衝突が起きます。

- どちらも `onOpen`（スプレッドシートを開いたときにメニューを作る関数。名前を変えられないトリガー名）を定義しています。同じプロジェクトに入れると後から読み込まれた側だけが有効になり、メニューが片方しか出ません。関数名の重複はこの `onOpen` だけです（`isAllDayEventSafe` はそれぞれ `cts_isAllDayEventSafe_`、`shift_isAllDayEventSafe_` という別名にしてあります）。
- どちらも `yyyy-MM-dd`（例: `2026-10-22`）という名前の日付シートを作ります。`CalendarToSheet.gs` の「日付ごとに分ける」で作るシートと、`Shift.gs` の日付シートが同じ名前になり、同じスプレッドシートで併用すると `Shift.gs` の日付シート（シフト欄を含む）を `CalendarToSheet.gs` の出力で上書きします。

**両方を1つのプロジェクトで使う場合**は、次のように `onOpen` を1つにまとめます。

1. `CalendarToSheet.gs` の `function onOpen()` を `function ctsOnOpen()` に、`Shift.gs` の `function onOpen()` を `function shiftOnOpen()` に名前変更します（中身は変えません）。
2. 別のファイルに、両方を呼ぶ `onOpen` を1つだけ定義します。

```js
function onOpen() {
  ctsOnOpen();   // メニュー「カレンダー取得」
  shiftOnOpen(); // メニュー「シフト作成」
}
```

3. 日付シートの衝突は、`CalendarToSheet.gs` の出力方法を「1シートにまとめる」にするか、別のスプレッドシートを使って避けます（この方法でも、貼り付け先シート名に日付名を指定しないでください）。

### CalendarToSheet.gs（カレンダー予定の時間割転記）

Google カレンダーの予定を取得し、時間割形式でスプレッドシートへ転記します。

**使い方**

1. スプレッドシートに `CalendarToSheet.gs` を追加します。
2. メニュー「カレンダー取得」→「① 設定シートを作成」を実行します（既存の「カレンダー設定」シートがあると初期化の確認が出ます）。
3. 「カレンダー設定」シートに、貼り付け先・向き・期間・時間帯・対象カレンダーを入力します。
4. メニュー「カレンダー取得」→「② 予定を取得して反映」を実行します。

**設定（「カレンダー設定」シートの B 列）**

| 行 | 項目 | 内容 |
| --- | --- | --- |
| 2 | 貼り付け先シート名 | 必須。「まとめる」ときの出力先 |
| 3 | 貼り付け開始セル | `A1` など。空欄は `A1` |
| 4 | 向き | `縦`（時刻が行方向）／`横`（時刻が列方向）。空欄は `縦` |
| 5・6 | 期間開始日・期間終了日 | `yyyy-MM-dd` 形式。終了日は開始日以降 |
| 7・8 | 開始時刻・終了時刻 | `HH:mm`。**不正・未入力は `09:00`／`18:00` を使い、実行前にダイアログで知らせます**（続行かキャンセルを選べます） |
| 9 | 時間刻み（分） | 1 以上の整数。**不正・未入力は 15 分を使い、同じく実行前に知らせます** |
| 10 | 終日予定を別枠で取得 | `する`／`しない` |
| 11 | 出力方法 | `1シートにまとめる`／`日付ごとに分ける` |
| 12 行目以降 | 対象カレンダー | A 列に名前、B 列にメールアドレス、C 列の背景色がその人の予定色。名前とメール（`@` を含む）がある行だけ使います |

- 出力方法を「日付ごとに分ける」にすると、日付ごとに `yyyy-MM-dd` という名前のシートを作ります（同名のシートがあれば上書きします）。
- 取得できなかったカレンダー（メールアドレスの誤り、閲覧権限や共有設定がない、取得時のエラー）は、「予定なし」ではなく取得失敗として、完了ダイアログとログに「名前（メール）・理由・失敗した日数」を表示します。その人の列は空欄で出力されます。
- 参加を辞退した予定は除外します。同じ時間帯に複数の予定があるときは先に取得した予定を表示します。
- 日をまたぐ予定（終了時刻が開始時刻より前になるもの）は時間割に表示しません。
- 題名が `=`、`+`、`-`、`@` で始まる予定は、数式として評価されないよう先頭にアポストロフィ（セルには表示されない文字列指定の印）を付けて書き込みます。
- 現状の制限: 「カレンダー設定」シートを「① 設定シートを作成」で作ると、11 行目の「出力方法」の行が対象カレンダーの見出し行（名前／メールアドレス／色）で上書きされます。そのため、作成直後の設定シートでは B11 を読んでも「日付ごとに分ける」になります。「1シートにまとめる」を使うときは、見出し行の位置が重なっている点に注意してください。

### Shift.gs（シフト自動割当）

複数メンバーの Google カレンダー予定を読み、日付シート（`yyyy-MM-dd`）に 15 分スロット単位でシフトを自動で割り当てます。月間目標・1日の上限／下限・メイン担当・週次担当・ロック・確定日などのルールを持ちます。ルールの詳細は、メニューで作る「使い方」シートにも書かれます。

**基本の流れ**

1. スプレッドシートに `Shift.gs` を追加します。
2. メニュー「シフト作成」→「初回セットアップ・設定」→「設定シートを作成/初期化」を実行します（「設定」「除外日」「使い方」シートができます）。
3. 「設定」シートの上部（1〜2 行目）と、5 行目以降のユーザー情報を入力します。
4. 「① カレンダー予定を反映」で日付シートを作ります（既存のシフトは保持されます）。
5. 「② シフトを自動作成（空き枠のみ）」を実行し、結果ダイアログの警告を確認します。必要に応じて手動で調整し、日が決まったら日付シート A1 の確定チェックを入れます。

**「設定」シート**

- 1〜2 行目: A 開始日／B 取得日数／C 開始時刻／D 終了時刻／E 月の稼働日数／F 予定時間計算用稼働日数／G 月間目標／H 1日上限／I 1日下限／J メイン担当1／K メイン担当2／L メイン担当外／M 管理者メール／N シフト登録キーワード／O 前後1hブロックキーワード。
- 5 行目以降（ユーザー）: A 名前／B メールアドレス／C 色／D 予定人月／E 予定時間（手入力。自動割当の目標値）／F 予定時間（目安。自動計算）／G・H 個人の開始・終了時刻。
- メールアドレスを複数書くセル（メイン担当・管理者メール）の区切りは、カンマ（`,` `，`）、読点（`、`）、セミコロン（`;` `；`）、空白です。キーワード（シフト登録・前後1hブロックなど）の区切りも、空白を除いて同じです。
- C2 と D2 は時刻として読み、開始が終了より前であることを「設定チェック」で確認します（`9:00` と `18:00` のような桁数の違いがあっても分単位で比較します）。

**メニュー「シフト作成」**

| メニュー | 内容 |
| --- | --- |
| ① カレンダー予定を反映 | カレンダーから予定を取得し、日付シートを作成・更新。既存のシフトと、ロックは本人名で復元（人数が変わって復元できなかったロックは完了メッセージに表示） |
| ② シフトを自動作成（空き枠のみ） | 手動シフトとロック列を保護して空き枠だけ自動で埋める |
| ②-2 指定期間だけ組みなおす | 開始日〜終了日だけ再割当。範囲外の既存割当は月間目標の消化として扱う |
| ③ 集計を更新 | 設定シートの集計だけ再計算 |
| 初回セットアップ・設定 | 設定シート／使い方シート／運用設定シート／キーワードルールシート／ユーザー属性シート／週次担当シート／テスト用シミュレーションシートの作成・更新と、キーワードルール・ユーザー属性の設定への反映 |
| 確認・分析・補填 | 不足日レポート、不足日だけ補填（安全）、空き時間を抽出 |
| 管理・診断 | シフト欄を初期化（全クリア）、シフトを自動作成（全クリア）、変更履歴シート、設定チェック |

「シフトを自動作成（全クリア）」は確認ダイアログに、削除されるシフト列の数（登録ユーザー数）を表示します。

**失敗・警告の表示**

- 予定を取得できなかったカレンダー（メールアドレスの誤り、権限・共有設定なし、取得時のエラー）は、「予定なし」とは別に、「① カレンダー予定を反映」の完了メッセージ、自動割当の結果ダイアログの警告欄（先頭）、不足日レポート・不足日の補填のダイアログに表示します。補填の確認ダイアログでは、取得できなかった人は予定なしとして扱われる旨を示してから続行かキャンセルを選べます。
- 題名が `=`、`+`、`-`、`@` で始まる予定は、先頭にアポストロフィを付けて文字列として書き込みます。
- 「不足日だけ補填（安全）」は、同時刻の担当者上限（運用設定の「同時刻の担当者上限」）と、ユーザー属性シートの同時禁止相手を、自動割当本体と同じ判定で守ります。

**未対応の設定（選べても動作に影響しないもの）**

- 「キーワードルール」シートで現在「設定へ反映」で反映されるのは、動作が `強制シフト`、`割当不可`、`終日除外` のルールだけです。`優先割当`、`低優先`、`重複許容` は未対応で、「前後バッファ分」「対象」列も未対応です（割当不可・終日除外の前後は運用設定の「特別予定バッファ分」が全ルール共通で使われ、対象は本人です）。
- 運用設定の「割当モード」の `研修期` は予約された選択肢で、標準と同じ動作です。`安全優先`、`カバー優先`、`繁忙期` だけが動作を変えます。

**既知の制限**

- 運用設定の「空き時間抽出: 実シフト優先キーワード」の既定値は `【作業】鹿島_SES` で、空欄にしても既定値に戻ります。別の組織で使うときは明示的に書き換えてください。
- 自動割当・不足補填の直前に、全日付シートのシフト欄を非表示シート `__シフトバックアップ` に保存し、`変更履歴` にバックアップ ID を記録します。バックアップから復元する機能（メニュー）はありません。戻すときは `__シフトバックアップ` を手作業で参照してください。
- 実行時間（6 分）の上限や同時実行への対策（分割実行、`LockService`）はありません。対象期間が長いときは期間を分けて実行してください。

## 動作確認

Node.jsがある環境では、`node --test tests/*.test.cjs` でテキストの解析・線の編集・図形挿入・レイアウト・画像カード・ボードファイルの検証テストを実行できます。ツール自体は引き続きHTMLファイルだけで動作します。
