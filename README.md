# かんたん業務フロー作成

Mermaidのように文字列で工程をつなぐだけで、担当者・部署ごとのスイムレーン型業務フロー図を自動作成できるHTMLツールです。図形を自由配置する必要はありません。

## 使い方

`index.html` をブラウザで開き、左側へ次のように入力します。

```text
営業:
問い合わせ受付 → 内容確認 → 見積作成

責任者:
見積作成 → 見積承認

営業:
見積承認 → 受注 → 納品完了
```

入力内容は右側へ即座に図として表示され、ブラウザに自動保存されます。

## 書き方

- スイムレーン：`営業:`や`経理:`のように、担当者・部署名の末尾へコロンを付けます。
- レーンをまたぐ接続：前のレーンにある工程名を、次のレーンの先頭にもう一度書きます。
- 通常の工程：`受付 → 内容確認 → 見積作成`
- 分岐ラベル：`対応可能？ -- はい → 見積作成`
- 開始・終了：`開始((問い合わせ受付))`、`完了((納品完了))`
- 条件分岐：`判断{対応可能？}`
- 通常処理：`確認[内容を確認]`
- `→` の代わりに `-->` または `->` も使用できます。

「書き方」ボタンからサンプルを選択でき、完成した図はSVG画像として保存できます。

入力途中の行や、矢印でつながっていない単独の工程もそのまま表示されます。同じ工程を別の行から参照しても、最初に指定した図形と表示名は維持されます。

## 便利な機能

- ブルー・グリーン・モノクロの配色切り替え
- プレビューの拡大・縮小・全体表示
- 長い工程名・レーン名の自動改行
- テキストファイルの読み込み
- 入力内容のコピーとブラウザへの自動保存
- SVG形式と高解像度PNG形式での画像保存
- レーン数と工程数のリアルタイム集計
