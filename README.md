# かんたん業務フロー作成

図形を直接操作する「図で編集」と、Mermaidのように工程をつなぐ「テキスト」の両方で、担当者・部署ごとのスイムレーン型業務フロー図を作成できるHTMLツールです。自動配置した図を、ドラッグで自由に調整できます。

## 使い方

`index.html` をブラウザで開くと、「図で編集」が表示されます。

1. 左側の「処理」「判断」「開始・終了」で図形を追加します。「担当」でレーンも追加できます。
2. 図形を選び、左側で名前・種類・色・担当を変更して「変更を反映」を押します。
3. 図形をドラッグして位置を調整します。別のレーンへ移すと担当も変わります。「グリッド」を外すか、Shiftを押しながら移動すると細かく配置できます。
4. 始点を選んで「この図形からつなぐ」を押し、終点をクリックすると接続できます。Escでキャンセルできます。
5. 選択した図形は「複製」「削除」で操作できます。線の編集画面では、その線だけを削除することもできます。

「戻す」「やり直す」は図形の移動・編集・追加・接続・削除・配置設定・テキストの変更に対応します。履歴は最大80操作で、再読み込みするとリセットされます。図形を削除すると、その図形につながる線も削除されます。前後の図形を勝手につなぎ直すことはありません。

「自動整列」で現在の向きの手動配置を解除できます。横方向と縦方向の配置は別々に保存されます。配置・図形の色・担当の変更も自動保存、TXT保存、SVG／PNG出力に反映されます。

キーボードでも操作できます。図形を選んだ状態で、矢印キーで移動（Shiftで1px）、Ctrl+Dで複製、Deleteで削除、Ctrl+Zで戻す、Ctrl+Shift+ZまたはCtrl+Yでやり直します。入力欄を編集中は文字入力が優先されます。MacではCtrlの代わりにCommandも使えます。

## テキストで入力

左側の「テキスト」へ切り替えると、次のように入力できます。

```text
営業:
問い合わせ受付 → 内容確認 → 見積作成

責任者:
見積作成 → 見積承認

営業:
見積承認 → 受注 → 納品完了
```

入力内容は右側へ即座に図として表示され、ブラウザに自動保存されます。

「TXT保存」で編集用テキストを保存し、「テキスト読込」で再編集できます。保存するファイル名にはフロー名が使われます。ブラウザの自動保存が利用できない場合も、TXT保存で入力内容を残せます。

## 書き方

入力欄の上にある「担当」「開始・終了」「処理」「判断」「矢印」ボタンからも追加できます。図形のボタンはカーソル位置に記法を挿入し、名前を選択するので、そのまま入力して変更できます。「担当」は現在の行の下にレーンを追加します。図形のIDは重複しないように自動採番されます。

- スイムレーン：`営業:`や`経理:`のように、担当者・部署名の末尾へコロンを付けます。
- レーンをまたぐ接続：前のレーンにある工程名を、次のレーンの先頭にもう一度書きます。
- 通常の工程：`受付 → 内容確認 → 見積作成`
- 線の文字：`受付 -- 確認後 → 承認 -- 承認済 → 完了`（途中の線にも指定できます）
- 開始・終了：`開始((問い合わせ受付))`、`完了((納品完了))`
- 条件分岐：`判断{対応可能？}`
- 通常処理：`確認[内容を確認]`
- `→` の代わりに `-->` または `->` も使用できます。

「使い方」ボタンからサンプルを選択でき、完成した図はSVG画像として保存できます。

入力途中の行や、矢印でつながっていない単独の工程もそのまま表示されます。同じ工程を別の行から参照しても、最初に指定した図形と表示名は維持されます。

## 画面から文字を変更

図形をクリックすると左側で編集でき、ダブルクリックすると文字編集画面を開きます。担当レーンの名前はクリックで変更できます。上部の「文字を編集」から対象を選ぶこともできます。表示名だけを変える場合、図形のID・種類・接続は保たれ、同じ図形への参照もまとめて更新されます。空の名前や、別の担当レーンと同じ名前への変更はできません。

## 線に文字や図形を追加

図の線をクリックするか、プレビュー上部の「線を編集」を押します。編集画面の「編集する線」から対象を切り替えられます。キーボードではTabで線を選び、EnterまたはSpaceで開けます。

- 「線に表示する文字」を入力して「変更を反映」を押すと、線の上に文字を表示します。空欄にして反映すると文字を消せます。
- 「図形の種類」と「図形に表示する文字」を指定して「図形を挿入」を押すと、線の途中に処理・判断・開始／終了の図形を追加し、前後を自動でつなぎます。線の文字は新しい図形の手前に残ります。線の文字も同時に変更できます。
- 追加先の担当レーンは編集画面に表示されます。変更は入力テキストにも反映され、自動保存・TXT保存・SVG／PNG出力に含まれます。
- 閉じるボタンまたはEscで、変更を反映せずに編集画面を閉じられます。反映後は入力欄のCtrl+Zで元に戻せます。

画面から追加した表示名は引用符付きの記法で保存されます（例：`工程1["内容 → 確認"]`、`受付 -- "承認後" → 完了`）。矢印や括弧を表示名に含められ、以前の記法もそのまま使えます。

## 重なる線・遠い接続・縦横切り替え

- 線は分岐・合流する位置と経路をずらして描き、色・線種でも区別します。交差部分には白い縁取りを入れています。モノクロ配色でも線種を変えて表示します。
- 同じ図形間でも、文字が異なる線（「はい」「いいえ」など）は別々に表示・編集できます。始点・終点・文字がすべて同じ記述は、同じ線への参照としてまとめます。
- 上部の「遠い線」を「番号で自動省略」にすると、3段階以上離れる接続、戻る接続、2レーン以上またぐ接続を「③へ」のような表示に変えます。
- 線の編集画面にある「接続の表示方法」で、その線だけ「線で表示」「番号で省略」を指定できます。「『遠い線』の設定に従う」で全体設定に戻せます。
- 「③へ」を押すと、同じ番号が付いた接続先の図形へ移動して強調表示します。番号は図形の追加に応じて自動で振り直され、接続先と常に対応します。
- 「図の向き」で「横方向 →」「縦方向 ↓」を切り替えます。縦方向では担当レーンが列になり、工程が上から下へ進みます。文字や図形自体は回転しません。

表示設定は入力テキストの `# @flow` コメントへ自動で保存されます。手動で編集する必要はありません。TXT保存・読み込みで設定も引き継がれ、SVG／PNGにも現在の向きと接続表示が反映されます。古いテキストは横方向・線で表示の設定で開きます。

## 画像・リンクをボードに置く

- スクリーンショットや画像をコピーし、**Ctrl+V**（Macでは⌘V）で貼り付けると、白い枠付きの画像カードを追加します。「画像」ボタンでファイルを選ぶ方法や、キャンバスへのドラッグ＆ドロップにも対応しています。
- カードをドラッグして自由に配置し、選択すると現れる右下のつまみでサイズを変えられます。通常は画像の比率を保ち、Shiftを押しながらのサイズ変更で枠の縦横を自由に変えられます。画像自体は引き伸ばさず枠内に収めます。
- 左側でタイトル、幅・高さ、枠の色を変更できます。複製・削除、矢印キーによる移動、Ctrl+D、Delete、戻す・やり直すも使えます。画像・リンクカードの位置は図の向きを切り替えても保たれます。
- 「リンク」からURLを登録するか、入力欄以外を選んでURLを貼り付けると、リンクカードを追加します。「埋め込みを表示」を押したときに、そのサイトをボード内に読み込みます。埋め込みを禁止するサイトやログインが必要なサイトは「リンクを開く」で確認してください。埋め込み専用URLを提供するサービスではそのURLも利用できます。
- **「ボード保存」**で画像データを含む `.board.json` を保存できます。「読込」から復元でき、別のブラウザやPCへの持ち運びにも使えます。従来のTXTには図形とカードの設定だけが入り、画像データは含まれません。
- 画像はこのブラウザのIndexedDB、入力内容はlocalStorageに自動保存します。ブラウザのデータ削除で消えるため、残したいボードはファイルにも保存してください。保存領域が使えないときは画面上に表示します。
- SVG／PNG出力にも画像とカードの枠が入ります。外部サイトの埋め込みは、タイトルとURLを表示した静止カードとして出力します。

PNG・JPEG・WebP・GIF・BMPを受け付けます（1枚20MBまで）。画像は長辺2000px以内に調整し、GIFは静止画になります。1ボード100カードまで、持ち運び用ボードの画像データは合計64MBまでです。画像は外部サービスへ送信しません。

## 便利な機能

- ブルー・グリーン・モノクロの配色切り替え
- 名前付きアイコンと操作説明付きのツールバー
- 図形・担当レーン・矢印をボタンで入力
- 線をクリックして文字の追加・変更、途中への図形挿入
- 図形・担当名をクリックして文字を変更
- 図形のドラッグ移動・レーン変更・種類と色の変更
- 図形の複製・削除と、クリックによる図形同士の接続
- 「戻す」「やり直す」と、自動整列
- 接続線の描き分けと、番号による遠い接続の省略・移動
- 横方向／縦方向のレイアウト切り替え
- 「使い方」を閉じるボタンとEscキー対応
- プレビューの拡大・縮小・全体表示（縦横を画面内に合わせ、編集中や画面サイズの変更にも追従）
- 長い工程名・レーン名の自動改行
- 編集用テキストファイルの保存・読み込み
- 入力内容のコピーとブラウザへの自動保存
- SVG形式と高解像度PNG形式での画像保存
- レーン数と工程数のリアルタイム集計

## 動作確認

Node.jsがある環境では、`node --test tests/flow-model.test.cjs` でテキストの解析・線の編集・図形挿入・レイアウト・画像カード・ボードファイルの検証テストを実行できます。ツール自体は引き続きHTMLファイルだけで動作します。
